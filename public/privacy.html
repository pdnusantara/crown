01Pendahuluan & Identitas Pengelola

Kebijakan Privasi ini menjelaskan bagaimana aplikasi Android Barberos.id (Application ID id.barberos.app, selanjutnya disebut “Aplikasi”) mengumpulkan, menggunakan, menyimpan, membagikan, dan melindungi data pribadi. Dokumen ini disusun untuk memenuhi Undang-Undang No. 27 Tahun 2022 tentang Pelindungan Data Pribadi (UU PDP) serta Kebijakan Data Pengguna Google Play.

Aplikasi ini adalah alat bantu manajemen dan kasir (POS) untuk usaha barbershop. Penggunanya adalah pemilik toko, admin, dan kasir/barber — bukan aplikasi untuk konsumen umum. Dengan mengunduh, memasang, atau menggunakan Aplikasi, Anda menyatakan telah membaca dan memahami Kebijakan Privasi ini.

Pembagian peran: pengendali dan pemroses data

  • Pemilik usaha (toko/tenant) adalah Pengendali Data (data controller) atas data pelanggan dan data operasional yang diinput melalui Aplikasi. Pemilik usaha menentukan data apa yang dikumpulkan dari pelanggannya, untuk tujuan apa, dan bertanggung jawab memiliki dasar hukum yang sah (mis. persetujuan pelanggan) atas pengumpulan tersebut.
  • Barberos.id sebagai penyedia Aplikasi bertindak sebagai Pemroses Data (data processor) — kami memproses data tersebut atas instruksi pemilik usaha, semata-mata untuk menjalankan layanan (menyimpan, menampilkan, menghitung laporan, mencadangkan). Kami tidak menggunakan data pelanggan toko untuk kepentingan kami sendiri.
  • Khusus untuk data akun pengguna Aplikasi (email, nama, nomor telepon staf) dan data teknis, Barberos.id bertindak sebagai Pengendali Data karena data tersebut diperlukan untuk mengelola akun, keamanan, dan hubungan langganan.

03Rincian Penggunaan Izin Perangkat

Aplikasi meminta izin Android berikut. Setiap izin hanya dipakai untuk fungsi yang disebutkan:

  • INTERNET — berkomunikasi dengan server Barberos.id untuk login, menyimpan transaksi, dan menampilkan data. Tanpa izin ini Aplikasi tidak dapat berfungsi.
  • ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION — mengambil titik lokasi hanya pada saat staf menekan tombol absensi/check-in kehadiran, untuk memverifikasi bahwa staf berada di lokasi kerja. Lokasi tidak diambil saat Aplikasi berjalan di latar belakang, tidak diambil terus-menerus, dan tidak digunakan untuk iklan atau profiling. Anda dapat menolak atau mencabut izin ini melalui Pengaturan Android; konsekuensinya fitur absensi berbasis lokasi tidak dapat digunakan, sedangkan fitur lain tetap berjalan.
  • BLUETOOTH / BLUETOOTH_CONNECT / BLUETOOTH_SCAN — menemukan dan terhubung ke printer struk thermal (ESC/POS) di sekitar Anda. Izin ini hanya untuk mencetak; data yang dikirim ke printer adalah isi struk, dan komunikasi terjadi secara lokal antara perangkat dan printer. Kami tidak menggunakan pemindaian Bluetooth untuk menentukan lokasi Anda dan tidak mengirimkan data Bluetooth apa pun ke pihak ketiga.

04Bagaimana Data Dibagikan

Data yang Anda input dikirim melalui koneksi terenkripsi ke server layanan Barberos.id dan disimpan di sana agar dapat diakses lintas perangkat serta ditampilkan dalam laporan. Selain itu, data hanya dibagikan dalam hal berikut:

  • Penyedia infrastruktur/hosting — pihak yang mengoperasikan server tempat data disimpan, terikat kewajiban menjaga kerahasiaan dan hanya memproses data untuk menjalankan layanan.
  • Layanan Google Play — digunakan untuk distribusi, pemasangan, dan pembaruan Aplikasi. Pemrosesan oleh Google tunduk pada Kebijakan Privasi Google.
  • Kewajiban hukum — bila diminta secara sah oleh pengadilan atau otoritas berwenang sesuai peraturan perundang-undangan yang berlaku.

Yang tidak kami lakukan — dan ini kami tegaskan:

  • Kami tidak menjual dan tidak menyewakan data pribadi Anda maupun data pelanggan toko kepada pihak mana pun.
  • Aplikasi tidak menampilkan iklan pihak ketiga dan tidak membagikan data untuk keperluan periklanan.
  • Aplikasi tidak melacak lokasi Anda di latar belakang.
  • Kami tidak menggabungkan data antar-toko; data setiap toko terpisah satu sama lain.

05Penyimpanan, Retensi, dan Keamanan Data

Tempat & lama penyimpanan

  • Data diproses dan disimpan pada server layanan Barberos.id.
  • Data disimpan selama akun toko masih aktif dan selama diperlukan untuk tujuan pada kebijakan ini.
  • Setelah akun dihentikan atau permintaan penghapusan disetujui, data akan dihapus atau dianonimkan dalam maksimal 30 (tiga puluh) hari kerja, kecuali data tertentu yang wajib kami simpan lebih lama berdasarkan peraturan perundang-undangan (mis. catatan penagihan/perpajakan). Salinan pada media cadangan (backup) akan terhapus mengikuti siklus rotasi cadangan, paling lama 90 hari.
  • Kami menyarankan Anda mengekspor data penting sebelum menghentikan penggunaan layanan.

Langkah keamanan

  • Seluruh komunikasi antara Aplikasi dan server menggunakan enkripsi HTTPS/TLS.
  • Token login disimpan pada penyimpanan aman perangkat (secure storage), bukan pada berkas biasa.
  • Kata sandi disimpan di server dalam bentuk ter-hash dan tidak dapat kami baca.
  • Akses data dibatasi berdasarkan peran dan cabang pengguna, serta dipisahkan antar-toko.
  • Pencadangan data dilakukan berkala untuk mencegah kehilangan data.

Meski demikian, tidak ada sistem yang sepenuhnya bebas risiko. Bila terjadi kegagalan pelindungan data pribadi, kami akan memberitahukan pihak yang terdampak dan otoritas berwenang sesuai ketentuan UU PDP.
